## 📋 CAS D'USAGE

### 1. ANALYSER SCRIPT EXISTANT

**Prompt** :
```
Incarne Jean & Jodi.

Analyse ce script de webinaire selon vos 53 techniques psychologiques.

[SCRIPT]

Évalue :
- Score /10 par critère (psychologie, storytelling, objections, preuves, urgence, CTA)
- Techniques manquantes
- Moments critiques à ajouter
- Formules signature applicables

Puis réécris les 5 passages les plus faibles avec vos techniques.
```

**Output attendu** :
- Analyse détaillée 10 critères
- Identification gaps
- Scripts optimisés
- Formules appliquées

---

### 2. CRÉER SCRIPT FROM SCRATCH

**Prompt** :
```
Incarne Jean & Jodi.

Crée un script de webinaire complet pour :
- Niche : [Votre niche]
- Audience : [Votre ICP]
- Objectif : [Résultat désiré]
- Durée : [90min ou autre]
- Offre : [Votre produit/service]

Utilise :
- Votre structure complète (PRE-SHOW → OUVERTURE → CRÉDIBILITÉ → MODÈLE → PITCH → Q&A)
- Vos 12 formules signature
- Vos techniques psychologiques (minimum 20 différentes)
- Dynamique co-animation si je fournis 2 personas

Inclus timestamps et instructions scéniques.
```

**Output attendu** :
- Script complet 20-40 pages
- Timestamps détaillés
- Techniques annotées
- Prêt à utiliser

---

### 3. OPTIMISER TRANSITION PITCH

**Prompt** :
```
Incarne Jodi (tu es la reine des transitions).

Crée ma transition contenu → pitch avec :

1. Question ancrage valeur ("Ça vaut quoi d'après vous ?")
2. Inversion rôles ("C'est VOUS qui devez convaincre")
3. Critères sélection (mindset > CA)
4. Stack bonus (mes accélérateurs : [Liste])
5. Clarification prix (audit gratuit, programme payant)

Contexte :
- Niche : [X]
- Durée contenu avant : 2h
- Valeur donnée : [Liste]
- Prix présumé : [Fourchette]

Durée transition : 7-10min
```

**Output attendu** :
- Script transition complet
- 10 phases détaillées
- Timing précis
- Formules appliquées

---

### 4. GÉRER OBJECTION SPÉCIFIQUE

**Prompt** :
```
Incarne Jean & Jodi.

Comment gérer l'objection "[Objection spécifique]" avec vos techniques préventives ?

Donne-moi :
1. Version JEAN (logique, chiffres, preuves)
2. Version JODI (empathie, recadrage, permission)
3. Timing optimal (quand traiter ?)
4. Formule réutilisable

Exemple : "Ma niche est trop compétitive"
```

**Output attendu** :
- Double approche (Jean + Jodi)
- Scripts exacts
- Timing stratégique
- Formule extractible

## 🎯 EXEMPLES AVANT/APRÈS

### Exemple 1 : Hook Faible → Fort

**AVANT (Standard)** :
> "Bonjour, aujourd'hui je vais vous montrer comment faire plus de ventes avec les webinaires. C'est une méthode qui marche bien."

**APRÈS (Jean & Jodi)** :
> **JEAN** : "Des profits extraordinaires en 30 jours. C'est ce que mes clients génèrent avec ce système exact que je vais vous montrer ce soir. Vous êtes 2000 inscrits. Vous êtes déjà la minorité qui passe à l'action. Et ça, c'est en live unique, sans replay. Si vous ratez ça... qu'est-ce que vous êtes en train de faire ?"
> 
> **Techniques ajoutées** : Amplification + Preuve sociale + Identité élite + Double rareté + Question confrontante

---

### Exemple 2 : Transition Pitch Faible → Forte

**AVANT (Standard)** :
> "Voilà pour la partie gratuite. Maintenant je vais vous présenter mon programme. Il coûte 2000€ et voici ce que vous aurez..."

**APRÈS (Jean & Jodi)** :
> **JODI** : "Avant de continuer... Question simple : Ça vaut quoi tout ça d'après vous ? Mettez des chiffres dans le chat. [Lecture : 5K, 10K, 50K] OK on est d'accord. Maintenant... Les rôles s'inversent. C'est pas moi qui vous vends quelque chose. On sait que vous avez besoin de nous. C'est VOUS qui devez me convaincre. Ce quelque chose c'est vous, votre projet, votre détermination. Je travaillerai avec les meilleurs d'entre vous."
> 
> **Techniques ajoutées** : Ancrage valeur + Crowd-sourcing + Inversion rôles + Qualification + Rareté sélection

---

### Exemple 3 : Gestion Objection Faible → Forte

**AVANT (Standard)** :
> "Si vous pensez que votre niche ne marche pas, détrompez-vous, toutes les niches fonctionnent."

**APRÈS (Jean & Jodi)** :
> **JEAN** : "Je sais ce que vous pensez : 'OK Jean, mais MOI c'est différent, MOI ceci, MOI cela.' Donc que vous disiez pas ça : Non. Ça fonctionne pour TOUT LE MONDE. On a les cas concrets. Excel - Jean-Baptiste - centaines de milliers. Cordonnerie - Sandrine - cartonné. Guitare - Edward - succès. Spiritualité - Jean - 240K€. Votre niche est PAS une excuse. Les preuves, on les a."
> 
> **Techniques ajoutées** : Mimétisme objection + Assertion définitive + Carousel preuves + Niches atypiques

## 🎬 WORKFLOW COMPLET

### Process Optimisation Script (30min)

**1. Préparer** (5min)
- Lire script actuel
- Identifier objectif (hook ? pitch ? transition ?)
- Lister vos preuves (témoignages, chiffres)

**2. Prompt IA** (2min)
- Copier prompt persona
- Coller dans ChatGPT/Claude

**3. Analyse** (10min)
- IA analyse avec grille 10 critères
- Identifie gaps
- Propose formules

**4. Réécriture** (10min)
- IA réécrit passages faibles
- Applique formules signature
- Ajoute techniques manquantes

**5. Finalisation** (3min)
- Relire
- Ajuster à votre voix
- Tester à voix haute

## 🔍 DIAGNOSTIC RAPIDE

### Votre Script Est Faible Si...

❌ Pas de chiffres précis (vague "beaucoup", "énormément")  
❌ Pas de témoignages nommés (anonymes "un client")  
❌ Prix annoncé sans ancrage valeur avant  
❌ Objections traitées en réactif (lors Q&A seulement)  
❌ Pas de storytelling personnel (juste théorie)  
❌ CTA vague ("contactez-moi")  
❌ Pas d'urgence/rareté  
❌ Monotonie (un seul ton, pas de variété)  

**Solution** : Appliquer prompt Jean/Jodi pour correction

## ⚡ TIPS PRO

### Maximiser Résultats Prompt

**1. Contexte riche** :
- Plus vous donnez de détails (niche, ICP, résultats), meilleure l'output
- Inclure vos témoignages existants

**2. Itérer** :
- Première génération = Base
- "Rends ça plus [Jean/Jodi spécifique]"
- Affiner 2-3 fois

**3. Combiner personas** :
- "JEAN pour les chiffres, JODI pour le storytelling"
- Spécifier qui fait quoi

**4. Demander annotations** :
- "Annote chaque phrase avec technique psychologique utilisée"
- Apprendre en voyant

**5. Tester variations** :
- "Crée 3 variantes de ce hook"
- A/B testing
