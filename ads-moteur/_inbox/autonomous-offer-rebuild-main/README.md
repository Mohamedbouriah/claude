## Ce que fait le skill

Tu donnes une offre (souvent faible, commoditisée, mal formulée) + idéalement des documents de research sur ta cible/ton marché. Le skill la **reconstruit depuis sa fondation** :

- **Value Equation** maximisée (Dream Outcome × Likelihood ÷ Time × Effort)
- **Value stack** avec valeurs attribuées (price anchoring)
- **Garantie** du bon type selon l'objection n°1 réelle
- **Bonus** qui tuent chacun une objection
- **Scarcity / Urgency** honnêtes
- **Naming MAGIC** (Magnet · Avatar · Goal · Interval · Container)
- **Pricing premium** + money model
- **3+ variations testables** par angle marketing, calibrées sur le stade de conscience de la cible

Générique : agence/B2B · coaching/info-produit · SaaS · e-commerce · local.

## Le processus (6 phases)

0. **Diagnostic & cadrage** — cible, marché, stade de conscience/sophistication, diagnostic Value Equation
1. **Construire** — la Value Equation (dream outcome → problèmes → solutions → delivery → trim & stack)
2. **Pricer** — premium + value stack + money model
3. **Amplifier** — scarcity, urgency, bonuses (11 règles), garantie (4 types), naming MAGIC
4. **Calibrer** — message-market match sur la cible réelle
5. **Variations** — 3+ angles testables
