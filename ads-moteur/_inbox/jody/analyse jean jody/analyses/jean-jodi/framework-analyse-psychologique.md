## PATTERNS SPÉCIFIQUES JEAN/JODI

### Patterns Jean (Identifiés analyse précédente)

1. **Chiffres massifs** : #AUTORITÉ #PREUVE_RÉSULTAT #AMPLIFICATION
   - "50 millions d'euros", "2000 webinaires"
   - Formule : [Nombre impressionnant] + [Résultat concret] + [Validation externe]

2. **Vitesse parole** : #ENGAGEMENT_COHÉRENCE #URGENCE
   - Rythme rapide maintient attention
   - Crée urgence subconsciente

3. **Mathématiques ROI** : #PREUVE_LOGIQUE #ANCRAGE
   - "Vous mettez 1€, vous récupérez 4€"
   - Formule : [Investment X] → [Return Y] (ratio clair)

### Patterns Jodi (Identifiés analyse précédente)

1. **Storytelling vulnérabilité** : #SYMPATHIE #IDENTIFICATION
   - Échec études, burnout, déclic
   - Formule : [Échec relaté] → [Déclic] → [Transformation]

2. **Permission émotionnelle** : #PERMISSION #RECADRAGE
   - "Vous avez le droit de...", "C'est OK si..."
   - Formule : Permission + Validation

3. **Questions engagement** : #QUESTION_RHÉTORIQUE #ENGAGEMENT_COHÉRENCE
   - "Est-ce que c'est clair ?", "Vous êtes chaud ?"
   - Formule : Question consensuelle (micro-oui)
