## 2. Taux d'optin (page de capture)

| Performance | % | Diagnostic |
|---|---|---|
| Catastrophique | < 15% | Page cassée ou mismatch pub/page |
| Faible | 15-25% | Promesse à retravailler |
| Correct | 25-30% | Tout fonctionne mais pas optimisé |
| Bon | 30-40% | Standard d'un setup réussi |
| Excellent | 40-50% | Promesse alignée parfaitement |
| Exceptionnel | 50%+ | Ne rien changer |

**Standards par contexte :**
- Trafic froid Meta Ads : 25-35%
- Trafic chaud (audience existante) : 50-70%
- Email warm list : 40-60%

## 3. Show-up rate (taux de présence webinaire)

| Performance | % | Diagnostic |
|---|---|---|
| Catastrophique | < 15% | Relances cassées |
| Faible | 15-20% | Manque de canaux de relance |

| Bon | 25-35% | Multi-canal en place |
| Très bon | 35-45% | Phone calls + WhatsApp + séquence mail solide |
| Exceptionnel | 45%+ | Standard à viser |

**Cas extrêmes documentés :**
- Liberty Bourse 150K : 53,5% (28K€ pub, 4 270 inscrits, 2 270 présents)
- Diane/Arthur 1er webi raté : 14% (setup défaillant numéro Texas)
- Joannie : 35% standard
